# Riverbend elder

Generated fantasy game artwork for the Riverbend rescue sequence.
Original sheet: elder-sheet.png, twelve frames, four columns and three rows.
Row one: intact cage, damaged cage, breaking cage, release.
Row two: four left-facing walking poses.
Row three: holding, raising, offering and handing over the amber power stone.

The game trims transparent padding and anchors each pose to the visible feet.
Runtime animation definitions: src/game/art/elderAnimations.js.
Rescue state machine: src/game/items/ElderRescue.js.
Posters: public/assets/story/elder-captive.png and elder-stone.png.

Created with OpenAI image generation for this project. Original generated
files remain in the Codex generated_images directory. The power stone is
saved as a story reward only; it does not change current player abilities.
