# Sitting Sprite Sheet

`dog-sit-sheet.png` was generated with the built-in image generation tool, using
`Frame 6 Walking Brown Dog Sprite-6.png` as the character reference. Original
assets are preserved. The two seated poses are registered in `dogAnimations.js`.

Prompt: Create a horizontal three-frame game sprite sheet of the same friendly
brown dog with cream chest and floppy ears, painted fantasy 2D style. Face right,
full body side view, consistent scale and paws baseline. First pose lowers the
haunches; second sits looking up at an offscreen hero; third remains seated with
a subtle tail wag and happy eyes. Transparent background, no glow, shadows,
scenery, cage, hero, borders or text. Preserve consistent anatomy without cropping.
